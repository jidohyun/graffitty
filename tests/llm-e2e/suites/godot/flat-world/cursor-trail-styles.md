# Cursor trail styles

In both Flat and Flat 2D:

1. Open a terminal and move its cursor across several lines.
2. Select View → Cursor Trail → Smear, Blaze, then Lightning. Confirm the
   corresponding stretching fill, amber trail, and branching bolt appear.
3. Select Off. No trail should remain; the selected menu item stays checked.
4. Select Lightning again and switch worlds. The choice remains active and the
   terminal shell keeps running.

The replay checks menu wiring, render settings, and shell preservation. Shader
appearance requires GPU rendering; headless replays do not validate pixels.
