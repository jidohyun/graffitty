# Visual preferences

Change the focused remote pane font independently and select every cursor trail style, including Off, while terminal output continues.

Run the shared `visual_preferences` scenario on the Mac touch wrapper and the actual Android APK. Assert per-pane font isolation, exclusive checked menu state, terminal output after each style change, no unexpected diagnostics and no stuck contacts. Menu actions use the application menu dispatcher; font controls use keyboard input. This validates configuration and continued rendering, not the artistic appearance of each shader.
