# Android multi-server

Run the shared `tests/client_scenarios/multiserver.gd` scenario (desktop entry: `tests/headless_remote_client_e2e.gd`) in the exported Android APK. Three isolated standalone servers provide three concurrent connections, one per server address. Named sessions on a server are selected through the Sessions panel; duplicate connections to that address are not separate servers. Verify three-finger left/right remote switching, short-swipe cancellation and end-of-list resistance (GE-07), then namespaced pane IDs, independent input and resizing, tab create/close, graph RPC authority, image restoration, selectable Unicode history, server Chromium frames and JavaScript state across detach/reattach. Repeat swipes with a sidebar docked: it moves with the desktop, while floating controls stay stationary. Cancel and settle must reset both workspace and sidebar through the shared presentation owner. Server PTYs must survive and unexpected diagnostics fail. Run `mise run android:test android-multiserver --serial SERIAL`.

Reconnect the same transport after dropping its socket and clearing its client image cache. Authentication must select the previously displayed session again, restoring its live shell, images and subsequent updates. A retained local session name alone does not establish attachment on the new socket.
