# Sign-up page project

This project runs inside Graffitty. The page in `app/` is served at {url}
(open that URL; do not open the file directly). `spec.md` describes the page and
`e2e.md` lists its E2E tests.

- Graffitty Chromium: run `gft skill chromium` for how to open and drive a
  Chromium pane. Open it above your own pane (`--side above`) and reuse it.
- Graffitty agents and graph messages: run `gft skill agents`. Use `gft graph send`
  to message a connected agent.
