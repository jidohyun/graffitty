# Tiling demo

Concept: one workspace reorganizes around three persistent, recognizable tasks.

The application is captured at 2400 × 1500 using the native desktop DPI scale,
then fitted uniformly into a 1344 × 840 frame at (288, 56) on a 1920 × 1080 canvas.
Composite the traffic lights over
their reserved native title-bar space, rather than adding a second title bar.
Clip the outer window corners and add a restrained shadow.

Background: #15181f. Subtitle: #f1f2f4, 36px Open Sans Semibold using the repository's
bundled font, centered in the independent lower strip. The app's monospace text
provides the contrasting font voice. Traffic-light colors follow the user's
reference: #ec6765, #f2ca44, #65c466. In the native Retina source, the circles are
28px wide with 46px center spacing, their first center at (34, 50). Scale the
overlay by the same 0.56 factor as the footage. The window's flat #4a4d54 backdrop
matches the reference's visible background.
The window is the focal element; the fixed subtitle is the secondary anchor.
Use a flat background so all motion and color changes come from the demonstration.
Keep the window and subtitle still throughout; no artificial camera moves.
Show pane creation followed by one tiling rearrangement.

The desktop chapter uses Castle, default spaces 1, 2, 3, with 0.5 terminal
background opacity. The Android chapter includes the approved One UI bars and
Slack notification.
