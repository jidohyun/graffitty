# Chat service icons

User-supplied SVGs, displayed in their original brand colours:

- Slack: https://commons.wikimedia.org/wiki/File:Slack_icon_2019.svg
- Telegram: https://commons.wikimedia.org/wiki/File:Telegram_2019_Logo.svg

These are service trademarks, used to identify the corresponding integrations.
See the source pages for authorship and licensing information. Slack's SVG adds
an explicit viewBox matching its original dimensions for scalable rendering.

- Discord: user-supplied official Blurple symbol. The CSS class was replaced with
  the identical inline fill for the SVG renderer.
