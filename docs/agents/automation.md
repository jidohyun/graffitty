# Automation nodes

Run a node in a Graffitty pane, then connect its ports in the graph.
Choose the task you need.

## Send or inspect

| Task | Guide |
| --- | --- |
| Send a prompt by hand | [Manual Prompt](manual-prompt.md) |
| Gather recent conversation | [Read Session File](read-session-file.md) |
| Run later or repeatedly | [Scheduled Trigger](scheduled-trigger.md) |
| See incoming event data | [Payload Inspector](payload-inspector.md) |

## Process messages

| Task | Guide |
| --- | --- |
| Route by a condition | [Filter](filter.md) |
| Evaluate, classify, or score with a model | [SystemOne](systemone.md) |
| Wait for every branch | [Parallel](parallel.md) |

## Notify someone

Use [desktop notifications](system-notification.md) or
[Telegram, Slack, and Discord](chat-integrations.md).

## Pause and resume

**Pause** keeps queued input. **Start** applies current fields and resumes;
**Ctrl+Enter** is the apply shortcut. A send already in progress may finish.
