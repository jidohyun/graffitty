# Send a prompt


```sh
gft node manual-prompt
```

Connect **Output** to a receiver. **Enter** sends; **Shift+Enter** inserts a newline.

- **Alt+Enter** also inserts a newline.
- **Up/Down** at the draft's edges recalls earlier prompts.
- Failed sends keep the draft.
- Checkpoints keep the draft and recent sent prompts, within a size limit.

See [Automation nodes](automation.md) for other tools.
