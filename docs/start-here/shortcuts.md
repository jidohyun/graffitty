# Keyboard shortcuts

The **prefix** is **Ctrl+A**.
Press and release it, then press the next key. **Escape** cancels.
You can also click the selected tab or the prefix indicator in the status line.
Split shortcuts use the characters shown; type them using your keyboard layout.

### Tabs

| After the prefix, press… | To… |
| --- | --- |
| **C** | Create a tab |
| **N** / **P** | Switch to the next / previous tab |

### Sessions

| After the prefix, press… | To… |
| --- | --- |
| **Shift+C** | Create a session |

### Panes

| After the prefix, press… | To… |
| --- | --- |
| **H**, **J**, **K**, **L** or arrow keys | Focus a neighboring pane |
| `\` | Split right |
| **-** | Split below |
| **&#124;** | Create a pane to the left |
| `_` | Create a pane above |
| **V** | Search tabs and panes |
| **Tab** | Toggle the filetree |
| **Backspace** | Open and focus the filetree |
| **R** | Settle typing effects |
| **E** | Balance tiled splits, or resize a floating pane to the main view |

Press the prefix twice to send that key to the terminal program.
Text fields keep their normal Select All shortcut.

## View and selection

| Action | macOS | Other desktop platforms |
| --- | --- | --- |
| Fit focused pane; press again to return | **Cmd+Enter** | **Ctrl+Shift+Enter** |
| Return to the main area | **Cmd+Alt+Enter** | **Ctrl+Shift+Alt+Enter** |
| Toggle side panels and status bar | **Cmd+B** | **Ctrl+Shift+B** |
| Focus the next / previous agent in the Agents panel | **Cmd+]** / **Cmd+[** | **Ctrl+Shift+]** / **Ctrl+Shift+[** |
| Switch to the next / previous session | **Cmd+Option+]** / **Cmd+Option+[** | **Ctrl+Shift+Alt+]** / **Ctrl+Shift+Alt+[** |
| Make the panel under the pointer larger / smaller / normal size | **Cmd+Plus** / **Cmd+Minus** / **Cmd+0** | **Ctrl+Plus** / **Ctrl+Minus** / **Ctrl+0** |
| Quick Select | **Ctrl+Shift+Space** | **Ctrl+Shift+Space** |
| Pan with a two-finger trackpad drag | Hold **Cmd** | Hold **Ctrl** |

[Quick Select](../everyday-use/quick-select.md) labels paths, URLs and other text so you can copy
them with the keyboard.

To change these controls, see [key bindings](../customize/configuration-keyboard.md#change-a-shortcut)
and [prefix settings](../customize/configuration-keyboard.md#change-the-workspace-prefix).
