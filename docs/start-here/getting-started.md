# First steps

## What’s in a workspace?

- **Pane:** a terminal, browser, or filetree.
- **Tab:** a group of panes for one task.
- **Session:** tabs and programs you can leave running and return to.
- **World:** the appearance of the space around your panes.

## Try these first

1. **Split:** click <img class="menu-icon" src="../images/pane/split-right.svg" alt="Split right" title="Split right" width="20" height="20"> or <img class="menu-icon" src="../images/pane/split-down.svg" alt="Split down" title="Split down" width="20" height="20"> in a terminal's title bar.
2. **Resize:** drag the divider between tiled panes.
3. **Zoom:** pinch to see more; double-click a pane's title to bring it into view.
4. **Return:** choose **View (<img class="menu-icon" src="../images/menu/eye.svg" alt="" width="18" height="18">) → Fit to Main Area**.

## Create a tab

The **prefix** is **Ctrl+A**.
Press and release it, then press:

| Key | Action |
| --- | --- |
| **C** | Create a tab |
| **N** / **P** | Next / previous tab |
| **V** | Search tabs and panes |

- See [all shortcuts](shortcuts.md).

## Browsers, files, and agents

- **Browser:** <img class="menu-icon" src="../images/pane/chromium.svg" alt="Chromium" title="Chromium" width="20" height="20">.
- **Filetree:** prefix, then **Tab** to toggle; **Backspace** to open and focus.
- **Coding agents:** follow [agent setup](../agents/agent-setup.md).

## Leave and return

- **Keep programs running:** choose **Detach** when closing the window.
- **Return to them:** **Sessions (<img class="menu-icon" src="../images/menu/panels-top-left.svg" alt="" width="18" height="18">) → All Sessions…**.
- **Save a layout for later:** create a [checkpoint](../everyday-use/checkpoints.md).

A checkpoint recreates a layout and resumes supported agent conversations; it does not preserve running programs.
