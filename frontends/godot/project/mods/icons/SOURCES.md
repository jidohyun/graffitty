# Panel icons

`chevron-down`, `chevron-right`, `plus`, `check`, `clock`, `layers`: Lucide
(ISC, `LUCIDE-LICENSE`), copied from herdr-app `defaults/mods/workspace-chrome`
with `currentColor` replaced by white so the panel runtime can tint them.
`zoom-in`, `rotate-3d`, `maximize-2`: Lucide (ISC, `LUCIDE-LICENSE`),
from `lucide-static` 1.70.0, with `currentColor` replaced by white; the status
line's switch icons.
`triangle-alert`: Lucide (ISC, `LUCIDE-LICENSE`), written from Lucide's path
data with white strokes; the status line's WebSocket video warning.
`funnel`, `arrow-up`, `arrow-down`: Lucide (ISC, `LUCIDE-LICENSE`), written from
Lucide's path data with white strokes; the Resource Monitor's filter and sort marks.
`mail`: Lucide (ISC, `LUCIDE-LICENSE`), written from Lucide's path data with
white strokes; Pane Status's messages awaiting delivery.
