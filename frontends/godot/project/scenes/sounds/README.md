# Agent attention audio

`agent-attention.ogg` is the user-supplied Audiio **droplet_notification_05**
(The Library by Empty Sea — UI 2, 2019), converted to Ogg Vorbis for Godot.
Only the compressed audio is stored and packaged; the source WAV and its
embedded artwork/metadata are not included.

This is a commercial sound asset, not covered by Graffitty's source-code
license. Public distribution must be covered by the owner's Audiio license;
no redistribution rights are asserted by this repository.

The client uses the same clip for both `blocked` and `done` by default.
Override or disable it with `[sounds]` in `client.toml`.
