# UI icons

- `pin.svg`, `pin-off.svg`: Lucide ISC icons from herdr-app
  `defaults/mods/workspace-chrome`, commit `e77f112`. Only `currentColor`
  replaced with `white`. See `LUCIDE-LICENSE`.

- `graffitty-logo.webp`: Graffitty's approved transparent icon + wordmark,
  identical to [the website header asset](https://graffitty.com/assets/logo.webp).
  Composed from `assets/branding/layers/prompt.png` and `wordmark.png` using the
  layout in `assets/branding/spec/composition.toml`, with transparent padding
  trimmed and resized to 900×364. Original artwork, not a third-party logo.

- `os-macos.svg`, `os-windows.svg`, `os-linux.svg`: Font Awesome Free 6.7.2
  [Apple, Windows and Linux brands](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/brands),
  copyright Fonticons, Inc., CC BY 4.0 (see `FONT-AWESOME-LICENSE`). Changed only
  to a 40×40 viewport and white fill. These identify the server's OS; the marks
  remain the property of their respective owners. Apple and Windows use the
  same silhouettes as RustDesk; Linux uses Font Awesome's licensed Tux artwork,
  not RustDesk's AGPL-specific asset.
- `ellipsis-vertical.svg`, `trash-2.svg`, `monitor.svg`, `plug.svg`, `settings.svg`,
  `ellipsis.svg`, `chevron-up.svg`, `square-terminal.svg`, `square-pen.svg`,
  `eye.svg`, `eye-off.svg`, `panels-top-left.svg`, `history.svg`, `circle-help.svg`: [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons),
  ISC license in `LUCIDE-LICENSE`. Only `currentColor` replaced with `white`.

- Resource monitor SVG and its license moved to `assets/icons/`; see
  `assets/icons/SOURCES.md` for attribution.

- `keyboard.svg`: [Lucide Keyboard](https://lucide.dev/icons/keyboard), downloaded from https://github.com/lucide-icons/lucide/blob/main/icons/keyboard.svg. ISC license in `LUCIDE-LICENSE`. Only `currentColor` replaced with `white`.

- `folder-tree.svg`: [Lucide Folder Tree](https://lucide.dev/icons/folder-tree), supplied SVG for the filetree button. ISC license in `LUCIDE-LICENSE`. Only `currentColor` replaced with `white` for theme tinting.

- `server.svg`: [Lucide Server](https://lucide.dev/icons/server), used for remote
  session groups. ISC license in `LUCIDE-LICENSE`; white stroke.

- `x.svg`: [Lucide X](https://lucide.dev/icons/x) 0.468.0, the pane close button.
  ISC license in `LUCIDE-LICENSE`. Only `currentColor` replaced with `white`.

- `microphone.svg`: a simple microphone outline drawn for the dictation button.

- Layout template SVG is DVC-managed at `assets/icons/lucide/layout-template.svg`;
  see `assets/icons/lucide/SOURCES.md` for attribution and license.
